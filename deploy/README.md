# Deploy

Check that you have cloned [vigil/vigil](https://github.com/vigil/vigil)
and currently are in `vigil/deploy` folder.

## Installation

> **Note:** The `install.sh` script and the `docker-compose` manifests have been deprecated.

Vigil now installs and runs through [Foundry](https://vigil.io/docs/install/docker/).

> **Already running Vigil via Docker Compose?** See the [Migration Guide](./MIGRATION.md) to transition your existing deployment to Foundry.

Please follow the latest installation instructions at [vigil.io/docs/install/docker](https://vigil.io/docs/install/docker/).
Foundry has support for **different platforms and architectures**, please review the project documentation for more details.

## Uninstall/Troubleshoot?

Go to our official documentation site [vigil.io/docs](https://vigil.io/docs) for more.
